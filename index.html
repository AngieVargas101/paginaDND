Acerca de

Este proyecto web tiene como finalidad mostrar una estructura moderna de sitio informativo con navegación sencilla, integración de contenido visual y una sección de estadísticas representada de forma amigable. Puede ser utilizado como base para proyectos universitarios, institucionales o demostrativos.


La página está organizada para facilitar la lectura, mejorar la experiencia de usuario y presentar contenidos relevantes relacionados con educación, análisis de información y promoción de espacios locales.

Objetivos del sitio

  • Presentar información con una interfaz atractiva y profesional.
  • Integrar recursos como imágenes, video y estadísticas visuales.
  • Difundir el trabajo de estudiantes en el desarrollo web.
  • Promover el interés por Riobamba como ciudad académica y turística.
